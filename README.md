# Construction Vehicles & Trucks (Mobile Web App)

An interactive, responsive mobile web game inspired by kid-favorite vehicle construction games (*com.trochoi.constructionvehicles*).

## Key Features
- **4 Complete Play Stages**:
  1. 🧩 **Vehicle Assembly**: Drag-and-drop vehicle puzzle parts to build Excavators and Dump Trucks.
  2. ⛽ **Fueling Station**: Insert nozzle, pump gas, and fill up the tank with liquid bubbling effects.
  3. 🏗️ **Construction Site**: Dig earth with excavator bucket, load dump truck, and pour building foundations.
  4. 🧼 **Car Wash & Polish**: Sponge soap bubbles, high-pressure water hose rinse, dryer blower, and sparkle polish!
- **Multi-Viewport Simulator**:
  - iPhone Portrait (`390 × 844`)
  - Mobile Landscape (`844 × 390`)
  - iPad Tablet (`768 × 1024`)
  - Fullscreen Responsive
- **Trilingual Localization**:
  - English (`en`)
  - 中文 (`zh`)
  - Bahasa Melayu (`ms`)
- **Procedural Web Audio Engine**:
  - 100% synthesized sound effects via Web Audio API (zero bulky mp3 downloads, instant loading, no lag).
- **Kid-friendly UX**:
  - Giant touch targets, intuitive drag-and-drop with physics snapping, particle celebrations, and visual cues.

## Getting Started
```bash
npm install
npm run dev
```
