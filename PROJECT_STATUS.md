# Project Status: Construction Vehicles & Trucks Game

## Current Summary
- Project initialized with Vite and connected to GitHub repository `gouzun/construction-vehicles-game`.
- Scaffolding underway with 4 interactive game stages (Assembly, Fueling, Site Work, Car Wash) for Excavator & Dump Truck.
- Multi-viewport simulator shell and Web Audio synthesizer in progress.

## Scope & Feature Table
| Feature | Status | Notes |
|---|---|---|
| Project Scaffolding | In Progress | Vite + Modern Web (Vanilla JS + SVG + Canvas + Web Audio) |
| Multi-Viewport Simulator | In Progress | Phone Portrait, Landscape, Tablet, Fluid Fullscreen |
| Trilingual i18n | In Progress | en, ms, zh via central `t()` |
| Web Audio Engine | In Progress | Synthesized procedural audio (engine, clanks, water, pump, fanfare) |
| Stage 1: Vehicle Assembly | In Progress | Drag & drop snapping parts (chassis, cabin, wheels, arm/dumper) |
| Stage 2: Fueling Station | Planned | Interactive gas nozzle, pump trigger, fuel level gauge |
| Stage 3: Construction Site | Planned | Interactive digging & dumping actions to raise building |
| Stage 4: Car Wash & Polish | Planned | Soap lathering, water spray rinse, blower dry, sparkle celebration |
